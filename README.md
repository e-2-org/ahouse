# A House Is Not A Home

## by Geraint Evans

A piece using a combination of drawn images and simple animation, to create an uneasy interactive journey through a suburban dwelling.

**Technical Director:** Chris Panton _- Panart_

**Produced by:** e-2

**Viewing requirements:** A modern browser with JavaScript enabled

## Layout

The original files are at the top of this repository. The current version of the site is in `docs/`, which is what GitHub Pages publishes. Summaries and transcripts of the Claude Code sessions are in `_sessions/`.
